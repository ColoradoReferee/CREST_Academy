## Privacy

This Software stores data locally in the user's browser via `localStorage`, including student progress, instructor configuration, and Anthropic API tokens (if Jeff-eree is enabled). No student data is transmitted to JAReferee LLC. Optional Google Sheets sync, when enabled by an instructor, transmits aggregate class data to the instructor's chosen Google Sheet.

PIN values used to gate the Instructor and Admin dashboards are configured per-school instance and are not published in this repository. They are provisioned to authorized personnel separately by CSA.
